## 정상 흐름

### S-01 아무것도 없는 정상 순찰

| 항목 | 내용 |
|------|------|
| 상황 | 시험장 경로를 한 바퀴 돌며 관찰 지점 3곳에서 멈췄다가 다시 출발합니다. 동물도 사람도 없습니다 |
| 시험 준비 | 관찰 지점 3곳에 표식, 경로 위에 아무것도 두지 않음 |
| 기대 결과 | 지점마다 `OBSERVE_SEC` 정차 후 출발. 자극 0회, 이벤트 기록 없음 |
| 지금 코드 | 🔶 자율주행(DRV-01)만 됩니다. 관찰 지점에서 멈추지 않습니다(DRV-06 `[미반영]`) |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | 거리센서가 켜진 채 시작, `[G]`로 자율주행. 서보는 중앙 | SAFE-10, DRV-01, AIM-05 |
| 2 | 관찰 지점 표식을 보고 정차, 구역 번호 기억 | DRV-06 |
| 3 | `OBSERVE_SEC` 동안 탐지. 아무것도 없음 | DET-01 |
| 4 | 복귀, 다시 순찰. 2~4를 지점마다 반복 | AIM-05, DRV-01 |

**문장으로 읽기**

1. 순찰을 시작하는 상황
   - 거리센서를 켠 상태로 프로그램을 시작하고, `[G]`를 누르면 자율주행을 시작한다.
   - 서보는 가운데(90°)에 둔다.
     - 카메라가 서보 위에 있는 경우 CNN이 정면 영상으로 학습했으므로, 서보가 돌아가 있으면 조향이 틀린다. 그래서 출발 전에 가운데로 맞춘다.
2. 관찰 지점에 도착한 상황
   - 표식을 보면 멈추고 구역 번호를 기억한다.
   - `OBSERVE_SEC` 동안 동물과 사람이 있는지 본다.
3. 아무것도 보이지 않은 상황
   - 기록을 남기지 않고 다시 출발한다.
     - 아무 일도 없었으므로 기록할 이벤트가 없다. 다음 지점에서 2번부터 반복한다.

### S-02 노루가 나타났다가 떠남 (대표 시나리오)

| 항목 | 내용 |
|------|------|
| 상황 | 관찰 지점 2에서 노루가 보입니다. 자극을 받고 화면 밖으로 걸어 나갑니다 |
| 시험 준비 | 노루 모형(또는 노루 영상을 띄운 화면)을 화면 오른쪽 위쪽에 둠. 자극 후 모형을 화면 가장자리 쪽으로 옮겨 치움. 사람은 화면 밖 |
| 기대 결과 | 서보가 노루 쪽을 향함, 자극 1회, 판정 이탈, 기록 1건, 서보 중앙 복귀 후 출발 |
| 지금 코드 | 🔶 노루가 보이는 동안 경적만 울리고 차는 그대로 달립니다(DET-02). 서보는 움직이지 않습니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | 관찰 지점 2에서 정차 | DRV-06 |
| 2 | 노루가 `CONFIRM_SEC` 동안 계속 보이고 신뢰도 `ANIMAL_CONFIRM_CONF` 이상 → 확정 | DET-03 |
| 3 | 노루 박스가 화면 오른쪽 위 → 서보 2는 오른쪽, 서보 1은 위로 돌아감 | AIM-02, AIM-03 |
| 4 | 이 구역 첫 대응이라 음향 A 선택 | STIM-01 |
| 5 | `STIMULUS_SEC` 동안 음향 A. 서보는 노루를 계속 따라감 | STIM-02, AIM-02 |
| 6 | `REOBSERVE_WAIT_SEC` 쉬고, 서보를 고정한 채 `REOBSERVE_SEC` 동안 재관찰 | OBS-01 |
| 7 | 노루 박스가 화면 가장자리로 간 뒤 사라지고 다시 안 보임 → 이탈 | OBS-01 |
| 8 | 기록: 구역 2, 노루, 음향 A, 대응 1회, 이탈, 사진 | LOG-01 |
| 9 | 서보 중앙 복귀, `SERVO_HOLD_SEC` 뒤 순찰 재개 | AIM-05 |

시간표 예시 (2026-11-23 초기값 기준, 값이 바뀌면 이 표는 참고용):

| 경과 | 상태 | 하는 일 |
|-----:|------|---------|
| 0.0초 | 관찰 | 정차, 노루 첫 탐지 |
| 1.0초 | 조준 | 확정 (`CONFIRM_SEC` 1.0), 서보 이동 시작 |
| ~2초 | 자극 | 조준 완료(오차 40픽셀 안)되면 음향 A 시작. 안 맞아도 조준 시작 3초 뒤(4.0초)에는 시작 |
| ~5초 | 재관찰 | 음향 3초 끝, 1초 쉼 |
| ~6~11초 | 재관찰 | 5초 동안 확인 → 이탈 |
| ~11초 | 기록, 복귀 | 저장, 서보 중앙 |
| ~12.5초 | 순찰 | 서보 고정(1.5초) 뒤 출발 |

**문장으로 읽기**

1. 관찰 지점에서 노루가 보이는 상황
   - 멈춘 채로 `CONFIRM_SEC` 동안 계속 보이는지 확인한다.
   - 계속 보이고 신뢰도가 `ANIMAL_CONFIRM_CONF` 이상이면 노루로 확정한다.
     - 한두 프레임만 보인 경우는 잘못 본 것일 수 있으므로 확정하지 않는다(S-08).
2. 노루로 확정한 상황
   - 노루 박스의 중심이 화면 가운데에서 떨어진 만큼 각도로 바꾼다.
   - 서보 2는 좌우로, 서보 1은 위아래로 돌려 노루 쪽을 향한다.
     - 노루가 화면 오른쪽 위에 있는 경우 서보 2는 오른쪽, 서보 1은 위로 돈다.
     - 오차가 `AIM_DEADBAND_PX` 안이면 이미 맞았으므로 더 돌리지 않는다. 계속 조금씩 움직이면 서보가 떨기 때문이다.
3. 조준을 마친 상황
   - 이 구역에서 처음 하는 대응이므로 음향 A를 고른다.
   - `STIMULUS_SEC` 동안만 소리를 내고, 그동안 서보는 노루를 계속 따라간다.
     - 조준이 `AIM_TIMEOUT_SEC` 안에 맞지 않는 경우에도 자극은 시작한다. 노루가 움직이는 중일 수 있기 때문이다.
4. 자극이 끝난 상황
   - `REOBSERVE_WAIT_SEC` 쉬고, 서보를 움직이지 않은 채 `REOBSERVE_SEC` 동안 다시 본다.
     - 서보(카메라)가 움직이면 화면 가장자리가 관찰 구역 경계가 아니게 되므로 고정한다.
   - 노루가 화면 가장자리로 간 뒤 사라지고 끝까지 다시 보이지 않으면 이탈로 판정한다.
5. 이탈로 판정한 상황
   - 구역, 종류, 신뢰도, 자극, 판정, 사진을 기록한다.
   - 서보를 가운데로 돌리고 `SERVO_HOLD_SEC` 기다린 뒤 순찰을 다시 시작한다.

### S-03 노루가 떠나지 않음

| 항목 | 내용 |
|------|------|
| 상황 | 자극을 두 번 받아도 노루가 그 자리에 있습니다 |
| 시험 준비 | 노루 모형을 화면 가운데에 두고 끝까지 움직이지 않음 |
| 기대 결과 | 자극 `MAX_RESPONSES`회(음향 A, 그다음 음향과 LED), 판정 잔류, 원격 화면에 "확인 필요", 그 뒤 순찰 재개 |
| 지금 코드 | 🔶 노루가 보이는 동안 경적만 계속 울립니다. 횟수 제한이 없습니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1~5 | S-02의 1~5와 같음 (음향 A) | |
| 6 | 재관찰: 시간의 절반 이상 보임 → 잔류 | OBS-01 |
| 7 | 대응 1회 < `MAX_RESPONSES` → 다시 조준 | OBS-02 |
| 8 | 직전 결과가 잔류라 한 단계 강하게: 음향과 LED | STIM-01, STIM-02 |
| 9 | 재관찰 → 또 잔류. 대응 횟수를 다 씀 | OBS-01, OBS-02 |
| 10 | 기록: 잔류, 대응 2회, 사용 자극 "음향 A, 음향과 LED" | LOG-01 |
| 11 | 원격 화면에 "확인 필요" | LOG-02 |
| 12 | 서보 중앙 복귀 후 순찰 재개 | AIM-05 |

**문장으로 읽기**

1. 첫 자극 뒤에도 노루가 남아 있는 상황
   - 재관찰 시간의 절반 이상 노루가 보이면 잔류로 판정한다.
   - 대응 횟수가 `MAX_RESPONSES`보다 적으면 다시 조준한다.
     - 직전 결과가 잔류였으므로 같은 소리는 효과가 없었다고 보고, 한 단계 강한 음향과 LED를 쓴다.
2. 두 번째 자극 뒤에도 남아 있는 상황
   - 대응 횟수를 다 썼으므로 더 자극하지 않는다.
     - 계속 자극하면 동물이 익숙해질 수 있고 주변에도 방해가 되므로 횟수를 제한한다.
   - 잔류로 기록하고 원격 화면에 "확인 필요"를 띄운다.
3. 관리자에게 넘긴 상황
   - 서보를 가운데로 돌리고 순찰을 다시 시작한다.

### S-04 자극 뒤 대상이 가려짐

| 항목 | 내용 |
|------|------|
| 상황 | 자극 뒤 노루가 화면 가운데에서 갑자기 안 보입니다 (작물 모형 뒤로 숨음) |
| 시험 준비 | 자극이 끝나면 노루 모형 앞을 판으로 가림. 모형은 화면 가장자리로 옮기지 않음 |
| 기대 결과 | 판정 관찰 불가 (이탈로 기록하지 않음). 다시 대응하지 않음 |
| 지금 코드 | 🔶 가려지면 1초 뒤 경적이 멈춥니다. 판정과 기록은 없습니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1~5 | S-02의 1~5와 같음 | |
| 6 | 재관찰 중 박스가 화면 가운데에서 사라짐 | OBS-01 |
| 7 | 가장자리로 간 기록이 없고, 보인 시간도 절반이 안 됨 → 관찰 불가 | OBS-01 |
| 8 | 기록: 관찰 불가 | LOG-01 |
| 9 | 서보 중앙 복귀 후 순찰 재개 | AIM-05 |

**문장으로 읽기**

1. 재관찰 중 노루가 화면 가운데에서 사라진 상황
   - 이탈로 판정하지 않는다.
     - 가장자리로 걸어 나간 것이 아니라 가운데에서 사라졌으므로, 떠난 것인지 가려진 것인지 알 수 없다.
   - 보인 시간도 절반이 안 되므로 잔류도 아니다. 관찰 불가로 판정한다.
2. 관찰 불가로 판정한 상황
   - 다시 자극하지 않고 기록만 남긴다.
   - 서보를 가운데로 돌리고 순찰을 다시 시작한다.
     - 화면에서 사라졌다는 것만으로 퇴치 성공으로 기록하지 않는다.

## 사람 보호

### S-05 사람만 나타남

| 항목 | 내용 |
|------|------|
| 상황 | 순찰 중 사람이 카메라 앞에 섭니다 |
| 시험 준비 | 경로 앞 또는 관찰 지점에 사람이 섬 |
| 기대 결과 | 바퀴 정지, 자극 0회, 서보 움직이지 않음, 기록 "사람으로 중지". 사람이 사라지면 순찰 재개 |
| 지금 코드 | 🔶 정지와 `PERSON STOP` 표시, 동물 경적 금지는 됩니다(SAFE-03). 기록은 없습니다(LOG-01 `[미반영]`). 사람이 안 보인 지 1초가 지나면 새 탐지 결과가 없어도 다시 출발합니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | 사람 탐지 → 바퀴 정지, 화면에 `PERSON STOP` | SAFE-03 |
| 2 | 자극 금지, 서보 그 자리에서 정지 | SAFE-06 |
| 3 | 기록: 사람으로 중지. 원격 화면에 "확인 필요" | LOG-01, LOG-02 |
| 4 | 최신 탐지 결과에 사람이 없으면 다시 출발 | SAFE-06, SAFE-03 |

**문장으로 읽기**

1. 순찰 중 사람이 보이는 상황
   - 바로 멈추고 화면에 `PERSON STOP`을 띄운다.
   - 소리, LED 같은 자극은 내지 않고 서보도 움직이지 않는다.
     - 사람 쪽으로 자극을 주면 위험하므로, 사람이 보이는 동안은 어떤 대응도 하지 않는다.
   - 사람은 동물보다 낮은 신뢰도에서도 사람으로 본다.
     - 사람을 놓치는 쪽이 동물을 놓치는 쪽보다 위험하기 때문이다.
2. 사람이 사라진 상황
   - 최신 탐지 결과에 사람이 없을 때만 다시 출발한다.
     - 탐지가 늦어져 결과가 오지 않는 경우는 사람이 없는 것인지 알 수 없으므로 출발하지 않는다(S-13).
   - "사람으로 중지"를 기록하고 원격 화면에 "확인 필요"를 띄운다.

### S-06 사람과 노루가 함께 나타남

| 항목 | 내용 |
|------|------|
| 상황 | 관찰 지점에 노루와 사람이 함께 보입니다 |
| 시험 준비 | 노루 모형 옆에 사람이 섬 |
| 기대 결과 | S-05와 같음. 노루가 확실하게 보여도 자극 0회 |
| 지금 코드 | 🔶 정지, 동물 경적 금지는 됩니다. 기록은 없습니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | 사람과 노루를 함께 탐지 | DET-01 |
| 2 | 사람이 우선 → 정지, 자극 금지, 서보 정지 | SAFE-03, SAFE-06 |
| 3 | 기록: 사람으로 중지 (탐지 종류에 노루도 적음) | LOG-01 |

**문장으로 읽기**

1. 노루와 사람이 함께 보이는 상황
   - 노루가 아무리 확실하게 보여도 자극하지 않는다.
     - 사람 보호가 동물 대응보다 우선순위가 높으므로(우선순위 3위 대 5위) 사람 규칙을 따른다.
   - 멈추고 서보도 움직이지 않는다.
2. 기록하는 상황
   - "사람으로 중지"로 기록하고, 탐지 종류에 노루도 함께 적는다.
     - 노루가 있었다는 사실은 관리자에게 필요한 정보이므로 버리지 않는다.

| 6 | 재관찰하지 않음. 판정 관찰 불가 | OBS-01 |

| 8 | 최신 결과에 사람이 없으면 서보 중앙 복귀 후 순찰 재개 | SAFE-06, AIM-05 |

**문장으로 읽기**

1. 자극을 주는 도중 사람이 들어온 상황
   - 남은 자극 시간과 상관없이 바로 끈다.
   - 이미 켜 둔 경적의 남은 프레임도 지운다.
     - 지금 코드는 남은 프레임만큼 더 울리므로, SAFE-06을 구현할 때 이 부분을 고친다.
   - 서보는 그 자리에서 멈춘다.
2. 자극을 멈춘 상황
   - 재관찰하지 않고 관찰 불가로 판정한다.
     - 자극을 끝까지 주지 못했으므로 노루가 떠났는지 판정할 근거가 없다.
   - "사람으로 중지"를 기록한다.
3. 사람이 사라진 상황
   - 최신 탐지 결과에 사람이 없으면 서보를 가운데로 돌리고 순찰을 다시 시작한다.
   - 장애물 경고 경적은 사람이 있어도 울린다.
     - 이 경적은 동물 기피용이 아니라 사람에게 로봇을 알리는 안전 신호이기 때문이다.

### S-11 순찰 중 장애물

| 항목 | 내용 |
|------|------|
| 상황 | 경로 위에 상자가 놓여 있습니다 |

| 지금 코드 | 🔶 경고, 정지, 자율주행 재출발은 됩니다. `[D]`를 눌러야 동작하고, 정지 거리는 아직 110mm(목표 200mm)이고, 코드상 비상등은 바로 꺼져서 깜빡이지 않습니다. 같은 프레임에 동물이 보이면 꺼진 경적이 다시 울립니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | `HORN_DISTANCE` 안 → 정지 표시, 브레이크 램프, 경적 | SAFE-01 |
| 2 | `STOP_DISTANCE` 안 → 정지, 경적 끄기 | SAFE-02 |
| 3 | 상자를 치움 → 자율주행이면 `RESTART_NUM` 프레임 뒤 출발, 수동 전진이면 멈춘 채로 | SAFE-02 |

**문장으로 읽기**

1. 앞에 장애물이 가까워지는 상황
   - `HORN_DISTANCE` 안에 들어오면 화면에 정지 표시를 띄우고 브레이크 램프를 켠다.
   - 자율주행이나 전진 중이면 경적을 울린다.
2. 장애물이 아주 가까운 상황
   - `STOP_DISTANCE` 안에 들어오면 바퀴를 멈추고 경적을 끈다.
     - 이미 멈췄으므로 경고를 계속 울릴 필요가 없다.
   - 같은 때 동물이 보여도 경적을 다시 켜지 않는다.
     - 장애물 정지가 동물 대응보다 우선순위가 높기 때문이다. 지금 코드는 다시 켜므로 고칠 곳이다.
3. 장애물을 치운 상황
   - 자율주행 중이었으면 `RESTART_NUM` 프레임 뒤 다시 출발한다.
   - 수동 전진 중이었으면 멈춘 채로 있고, `[Up]`을 다시 눌러야 움직인다.
     - 수동 운전은 사람이 직접 하는 것이므로 로봇이 마음대로 다시 움직이지 않는다.

2. 대응 중에 탐지가 멈춘 상황
   - 탐지 결과가 `DETECT_STALE_SEC`보다 오래되면 탐지가 멈춘 것으로 본다.

3. 그 뒤의 상황
   - 순찰을 계속할지, 멈추고 관리자를 부를지는 아직 정하지 않았다(규칙 11절).

     - 짧은 간격으로 계속 자극하면 동물이 빨리 익숙해지므로 쉬는 시간을 둔다.
2. 쉬는 시간이 지난 뒤 다시 나타난 상황
   - S-02처럼 대응하되, 이 구역에서 마지막으로 쓴 것과 다른 자극을 고른다.
     - 같은 자극을 반복하면 익숙해질 수 있으므로 돌려 가며 쓴다.

### S-15 운영자가 직접 끼어듦

| 항목 | 내용 |
|------|------|
| 상황 | 조준 중에 운영자가 서보 키를 누르거나 `[Space]`로 멈춥니다 |
| 시험 준비 | S-02 3단계(조준) 중에 `e`(서보 2, 소문자) 키, 그다음 `[Space]` |
| 기대 결과 | 서보 키: 자동 조준이 `MANUAL_OVERRIDE_SEC` 동안 멈추고 키대로 움직임. `[Space]`: 바퀴, 자극, 조준이 모두 멈추고 `[G]`를 누를 때까지 기다림 |
| 지금 코드 | 🔶 서보 키와 바퀴 정지는 됩니다(AIM-01, DRV-03). 자동 조준이 없어서 "자동을 멈추는" 부분은 시험할 수 없습니다. `[Space]`를 눌러도 울리던 경적과 서보 연속 이동은 멈추지 않습니다 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | 서보 키 → 자동 조준 잠시 멈춤, 키 조작 따름 | AIM-06, AIM-01 |
| 2 | `MANUAL_OVERRIDE_SEC` 지나면 자동 조준 다시 | AIM-06 |
| 3 | `[Space]` → 바퀴, 자극, 경적, 조준, 서보 연속 이동 모두 정지 | DRV-03, SAFE-09 |
| 4 | `[G]`를 누르면 서보 중앙 정렬 후 순찰 다시 시작 | AIM-05, DRV-01 |

**문장으로 읽기**

1. 조준 중에 운영자가 서보 키를 누른 상황
   - 자동 조준을 `MANUAL_OVERRIDE_SEC` 동안 멈추고 키대로 움직인다.
     - 사람이 직접 조작하는 것이 자동 판단보다 우선순위가 높기 때문이다(우선순위 4위 대 5위).
   - 서보 2 키는 소문자로 누른다.
     - 대문자는 방향키와 같은 값이라 서보 대신 차가 움직일 수 있다.
   - 시간이 지나면 자동 조준을 다시 한다.
2. 순찰 중에 운영자가 서보 키를 누른 상황
   - 카메라가 서보 위에 있는 경우 바퀴를 멈추고 자율주행을 끈다(AIM-07).
     - 카메라가 돌아간 채로 달리면 조향이 틀리기 때문이다.
3. 운영자가 `[Space]`를 누른 상황
   - 바퀴, 자극, 경적, 자동 조준, 서보 연속 이동을 모두 멈춘다.
     - 수동 정지는 가장 높은 우선순위이므로 어떤 상태에서도 다른 동작을 남기지 않는다. 지금 코드는 바퀴만 멈추므로 SAFE-09에서 보완한다.
   - `[G]`를 다시 누를 때까지 순찰도 대응도 시작하지 않는다.
