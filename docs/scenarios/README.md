# 동작 시나리오

순찰 로봇이 실제 상황에서 처음부터 끝까지 어떻게 움직이는지 이야기 순서로 적은 문서입니다.
규칙 하나하나는 [비즈니스 규칙](../business-rules/README.md), 모듈 사이 형식은 [인터페이스 명세](../software/interfaces.md)에 있고, 이 폴더는 규칙들이 이어져서 어떤 흐름이 되는지를 보여 줍니다.
시나리오는 그대로 시험 항목으로도 씁니다. 모형이나 화면 영상으로 상황을 만들고, "기대 결과"와 같은지 확인합니다.

| 파일 | 내용 |
|------|------|
| [README.md](README.md) | 이 안내서: 목록, 읽는 법, 고치는 법 |
| [scenarios.md](scenarios.md) | 시나리오 본문 |

## 1. 목록

| 번호 | 시나리오 | 기대 판정 | 지금 코드 |
|------|----------|-----------|-----------|
| S-01 | 아무것도 없는 정상 순찰 | 기록 없음 | 🔶 일부 |
| S-02 | 노루가 나타났다가 떠남 (대표 시나리오) | 이탈 | 🔶 일부 |
| S-03 | 노루가 떠나지 않음 | 잔류, 관리자 확인 | 🔶 일부 |
| S-04 | 자극 뒤 대상이 가려짐 | 관찰 불가 | 🔶 일부 |
| S-05 | 사람만 나타남 | 사람으로 중지 | 🔶 일부 |
| S-06 | 사람과 노루가 함께 나타남 | 사람으로 중지 | 🔶 일부 |
| S-07 | 대응하는 도중 사람이 나타남 | 사람으로 중지 | 🔶 일부 |

| S-09 | 관찰 지점이 아닌 곳에서 멧돼지를 만남 | 이탈 / 잔류 / 관찰 불가 | 🔶 일부 |
| S-10 | 노루가 두 마리 | 대상 1마리 기준 판정 | ⬜ 불가 |
| S-11 | 순찰 중 장애물 | 기록 없음 | 🔶 일부 |
| S-12 | 자극 도중 장애물 | 관찰 불가 | ⬜ 불가 |

| ✅ 가능 | 지금 코드로 기대 결과대로 시연됨 |
| 🔶 일부 | 일부 단계만 됨. 시나리오마다 "지금 코드" 칸에 무엇이 되는지 적음 |
| ⬜ 불가 | 필요한 규칙이 모두 `[미반영]` |

## 2. 읽는 법

시나리오 하나는 "개요 표", "흐름 표", "문장으로 읽기" 세 부분입니다.
표는 빠르게 훑거나 시험할 때, 문장은 처음 읽는 사람이 이유까지 이해할 때 봅니다. 둘은 같은 내용이므로 하나를 고치면 다른 하나도 고칩니다.

```markdown
### S-00 시나리오 이름

| 항목 | 내용 |
|------|------|
| 상황 | 무슨 일이 일어나는가 |
| 시험 준비 | 시험장에서 이 상황을 어떻게 만드는가 |
| 기대 결과 | 끝났을 때 로봇 상태와 기록 |
| 지금 코드 | 지금 코드로 하면 어떻게 되는가 |

| 단계 | 로봇 | 규칙 |
|:---:|------|------|
| 1 | 로봇이 하는 일 | 근거 규칙 번호 |

**문장으로 읽기**

1. ~한 상황
   - ~한다.
   - ~의 경우는 ~한다.
     - ~인 경우 ~했으므로 ~한다.
```

- 시간과 거리는 파라미터 이름으로 적습니다(예: `STIMULUS_SEC`). 숫자는 [parameters.md](../business-rules/parameters.md)에만 있습니다.
- 숫자로 감을 잡을 수 있게, S-02에만 초기값을 넣은 시간표 예시를 붙였습니다.
- 상태 이름(순찰, 관찰, 조준, 자극, 재관찰, 기록, 복귀)은 [규칙 README 2절](../business-rules/README.md#2-상태-흐름)과 같습니다.

## 3. 고칠 때

1. 규칙이 바뀌면 그 규칙 번호를 쓰는 시나리오를 찾아(`grep -n "AIM-02" docs/scenarios/scenarios.md`) 흐름 표를 고칩니다.
2. `[미반영]` 규칙이 구현되면 그 규칙을 쓰는 시나리오의 "지금 코드" 칸과 1절 목록을 고칩니다.
3. 새 시나리오는 다음 번호를 쓰고 1절 목록에 한 줄 넣습니다. 지운 번호는 다시 쓰지 않습니다.
4. 시험에서 기대 결과와 다르게 나오면 시나리오를 고치지 말고 먼저 원인(코드 / 규칙 / 시나리오)을 가립니다.

## 4. 시험과의 관계

[PROJECT_PLAN.md](../planning/PROJECT_PLAN.md) 정량 목표 중 아래 항목은 시나리오를 반복해서 잽니다.

| 정량 목표 | 시나리오 | 횟수 |
|-----------|----------|------|
| 사람 동반 시 자극 작동 0회 | S-05, S-06, S-07 | 준비한 시험 전부 |
| 결과 판정 정확도 90% 이상 | S-02(이탈), S-03(잔류), S-04(가림) | 각 10회 |
| 장애물 대응 (전방 정지) | S-11 | 속도별 |
| 연속 동작 20분 이상 | S-01에 S-02, S-03을 섞어 반복 | 1회 20분 이상 |

모형이나 화면 영상으로 한 결과는 실제 야생동물 퇴치 성공률로 보고하지 않습니다.
