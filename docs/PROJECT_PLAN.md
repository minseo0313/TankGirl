## 프로젝트 배경 및 필요성

농경지에 접근하는 야생동물을 발견하고 대응하기 위해서는 여러 구역을 관찰하고 침입 여부를 확인해야 한다.
울타리나 고정식 기피장치는 접근 제한과 대응에 활용될 수 있으나, 고정된 위치에서 반복되는 자극에 동물이 익숙해질 가능성이 있다.
2025년 엘크와 검은꼬리사슴을 대상으로 한 연구에서도 고정식 기피장치에 대한 적응이 관찰됐으며, 음향과 점멸광을 함께 제공했을 때 도피 반응이 높고 적응이 늦어지는 결과가 보고됐다.
다만 이 결과가 고라니나 이동형 장치에도 동일하게 적용된다고 단정할 수는 없다.

본 프로젝트는 농경지의 여러 관찰 지점을 순회하고, 동물 발견 후 자극 제공과 재관찰을 연결하는 초소형 로봇을 개발한다.
단순히 동물 발견 시 소리를 재생하는 데서 그치지 않고, 대응 후 대상이 관찰 구역에 남아 있는지 확인하여 관리자에게 결과를 제공한다.
고라니를 대표 사용 시나리오로 설정하되, 실제 종 분류 성능은 확보한 평가 영상으로 검증한다.

소형화의 목적은 작물 모형 사이에 조성한 좁은 관리 통로에 접근하는 것이다.
기존 Raspberry Pi 기반 자율주행차의 카메라 기반 주행 기능을 유지하면서 LCD를 제외하고 차체, 전원, 배선 및 출력장치 배치를 최적화한다.
평탄한 모사 환경에서 통로 폭에 따른 주행 성공률과 작물 모형 접촉 여부를 측정하여 소형화가 임무 수행에 미치는 영향을 확인한다.
실제 농장의 비포장 주행과 야생동물 기피 효과는 후속 현장 검증 대상으로 구분한다.

## 프로젝트 목표

Raspberry Pi 4B 4GB, microSD 32GB 이상, 카메라와 VL53L0X 거리센서를 사용하고 기존 aicar의 영상 획득, 데이터 생성, 모델 학습 및 자율주행 기능을 유지한다.
전체 차체를 배터리, 바퀴, 커넥터와 배선을 포함하여 9 cm × 7 cm × 7 cm 이내로 설계하며, Wi-Fi 기반 원격접속으로 운용한다.

1. 지정된 협소 통로를 자율주행하고 관찰 지점에 정차하는 기능을 구현한다. 전방 장애물을 감지하면 주행을 중단한다.
2. 관찰 지점에서 목표 동물과 사람을 구분한다. 사람이 함께 탐지되거나 분류가 불확실하면 기피 자극을 작동시키지 않고 기록과 알림만 제공한다.
3. 작동 조건을 충족한 경우 정차 상태에서 제한된 시간 동안 음향 또는 음향과 LED를 제공한다. 최근 사용한 자극과 직전 대응 결과를 고려하는 규칙 기반 선택 로직을 구현한다.
4. 자극 이후 재관찰하여 대상의 잔류, 관찰 구역 이탈 확인 또는 관찰 불가 상태를 판정한다. 시각, 관찰 구역, 탐지 종류, 사용 자극과 판정 결과를 기록하고 원격 화면에 표시한다.
5. 차체 크기, 협소 통로 주행 성능, 탐지 성능, 대응 절차 및 연속 동작시간을 평가한다. 모형이나 영상 기반 시연 결과는 실제 동물의 퇴치 성공률로 해석하지 않는다.

## 자료 조사 및 전공지식 적용 계획

1. **임베디드 시스템**: Raspberry Pi GPIO와 전원 구조, 카메라 인터페이스, VL53L0X의 I²C 통신을 조사한다. 모터와 출력장치의 최대 소비전류를 검토하고 전원 안정성을 확인한다.
2. **구동 및 제어**: 기존 aicar의 조향·속도 제어 방식을 분석하고 소형 모터와 모터드라이버를 선정한다. 주행 속도에 따른 정차 오차와 장애물 제동거리를 측정한다.
3. **영상처리와 딥러닝**: OpenCV 전처리와 PyTorch CNN 기반 조향각 회귀를 적용한다. 동물 탐지 모델은 Raspberry Pi에서 실행 가능한 크기를 검토하고 입력 해상도, 처리 지연 및 정확도를 비교한다.
4. **데이터 구성과 평가**: 주행과 탐지 데이터를 용도별로 관리하고 학습·검증·시험 데이터를 분리한다. 같은 촬영 구간의 유사 프레임이 학습과 시험에 동시에 포함되지 않도록 촬영 세션 단위로 분리한다. 주야간, 거리 및 가림 조건별 실패 사례를 분석한다.
5. **서비스 로직**: 순찰, 관찰, 자극 제공, 재관찰, 기록 및 복귀 상태를 정의한다. 동일 대상의 이동과 가림을 구분하고 관찰이 불가능한 경우 결과를 미확인으로 처리한다.
6. **네트워크**: Wi-Fi를 통한 원격접속과 기록 조회 기능을 구현한다. 외부 서비스에 의존하지 않는 로컬 조회 화면을 우선 구축한다.
7. **기구설계**: CAD로 보드, 배터리, 구동부, 카메라와 배선을 배치한다. 무게중심, 바퀴 간격, 카메라 시야, 발열 및 정비 접근성을 고려하여 3D 프린팅 차체를 제작한다.
8. **연구 근거 검토**: 기피 자극의 반복 노출과 동물 반응에 관한 연구를 조사한다. 연구 대상 종과 시험 환경을 확인하고 실제 기피 효과와 기능 시연을 구분한다.

## 결과물 설계 및 구현계획

### 1. 사용 환경과 운용 방식

지면 재배 채소 구역을 모사한 실내 시험장에 평탄한 관리 통로와 관찰 지점 3곳을 조성한다.
로봇은 지정 경로를 순회하며 각 지점에서 정차해 관찰한다.
구역 번호는 시각 표식 등을 이용해 확인하며, 초기 구현에서는 GNSS와 자유 경로 탐색을 제외한다.
목표 동물을 추격하거나 접촉하지 않고 순찰 경로 위에서 대응한다.

### 2. 하드웨어 구성

공통 필수 장비인 Raspberry Pi 4B 4GB, microSD 32GB 이상, 카메라 및 VL53L0X를 유지한다.
모터, 모터드라이버와 전원부를 포함한 전체 배치를 검토하고 소형 스피커, 구동용 증폭 회로와 LED를 추가한다. LCD는 사용하지 않는다.
야간 기능은 기존 카메라의 적외선 감도와 교체 허용 여부를 먼저 확인한 후 NoIR 카메라와 IR 조명의 적용 여부를 결정한다.
IR 조명과 기피용 가시광 LED는 목적이 다른 장치로 구분한다.

### 3. 시스템 블록 구성

```
주행        카메라 → 영상 전처리 → CNN 조향각 예측 → 조향·속도 제어 → 모터드라이버 → 바퀴
장애물 대응  VL53L0X → 전방 장애물 판단 → 주행 정지
서비스      관찰 영상·구역 번호 → 목표 동물 및 사람 탐지 → 작동 허용 판단 → 음향·LED 출력
            → 재관찰 → 결과 판정 → 저장·원격 표시
```

VL53L0X는 전방 장애물 감지에 사용하며, 카메라에 보이는 동물의 정밀 거리 측정 수단으로 간주하지 않는다.

### 4. 소프트웨어 동작

1. 지정 경로를 저속 주행한다.
2. 관찰 지점에서 정차하고 여러 프레임을 확인한다.
3. 사람이 탐지되거나 목표 분류가 불확실하면 자극을 중지하고 기록한다.
4. 목표 동물이 지정 관찰 구역에 존재하며 작동 조건을 충족하면 최근 사용 이력을 고려해 자극을 선택한다.
5. 설정 시간 동안 자극을 제공하고 같은 위치에서 재관찰한다.
6. 관찰 구역 경계를 넘어가는 움직임이 확인되면 이탈, 계속 존재하면 잔류, 가림이나 추적 실패로 확인할 수 없으면 관찰 불가로 판정한다.
7. 잔류 시 초기 설정 기준 최대 2회까지 대응하며, 이후에는 관리자 확인 요청을 표시한다.
8. 사진과 결과를 저장하고 순찰을 재개한다.

수동 정지 명령과 장애물 정지는 서비스보다 우선한다. 화면에서 대상이 사라졌다는 이유만으로 퇴치 성공을 기록하지 않는다.

### 5. 제작 및 시험 절차

구매 전 전체 부품의 실제 치수와 커넥터 공간을 반영한 3D 배치 검토를 진행한다.
카메라 하나로 주행과 동물 관찰에 필요한 시야를 확보할 수 있는지 먼저 시험한다.
이후 회로 연결, 수동주행, 차체 제작, 주행 데이터 수집과 모델 학습을 수행한다. 객체 탐지와 출력 제어를 개별 검증한 다음 통합한다.

기능 시연에서는 동물 모형과 영상 자료 등을 사용해 탐지 및 상태 전환을 확인한다.
별도로 실제 동물이 촬영된 주야간 평가 영상에서 탐지 성능을 측정한다.
모형과 화면 재생 기반 결과는 실제 야생동물 반응 검증과 구분하여 보고한다.

### 6. 기록 및 평가

기록 항목은 이벤트 번호, 시각, 관찰 구역, 탐지 종류와 신뢰도, 사용 자극, 재관찰 시간, 판정 결과 및 사진으로 구성한다.
통로 폭과 조명 조건별 결과를 비교하여 주행 실패와 탐지 실패를 분리해 분석한다.
실제 동물 실험이 없는 경우 음향별 기피 성공률, 적응 감소 및 농작물 피해 감소를 성과로 주장하지 않는다.

### 7. 부품 구매계획

기존 보유 장비를 우선 활용하고 소형 구동부, 배터리 및 전원부, 스피커와 증폭 회로, LED, 배선 및 체결부품을 조사한다.
야간 카메라와 IR 조명은 호환성 및 공간 검토 후 구매 여부를 결정한다.
정확한 모델, 수량, 단가, 크기, 무게, 전압, 최대 소비전류와 구매처 URL을 포함한 BOM을 별도로 작성한다.
총예산은 실제 견적을 확보한 후 산정한다.
