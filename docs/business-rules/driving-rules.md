## 1. 주행 (DRV)

### [초기반영] DRV-01 자율주행 조향

| 항목 | 내용 |
|------|------|
| 언제 | 순찰 |
| 조건 | `[G]` 또는 `[Home]`을 눌렀고 학습 모델(`.pt`)이 있음 |
| 동작 | 카메라 영상으로 CNN이 조향각을 예측하고, 왼쪽 모터 = `RUN_SPEED` + 조향각, 오른쪽 모터 = `RUN_SPEED` - 조향각으로 달립니다 |
| 예외 | 모델 파일이 없으면 수동 주행(DRV-02)만 됩니다 |
| 값 | `RUN_SPEED`, `ANGLE_GAIN` |
| 구현 | `aicar/ar.py` 자율 주행 모드 조향 각도 검출 블록 |

### [초기반영] DRV-02 수동 주행

| 항목 | 내용 |
|------|------|
| 언제 | 모든 상태 (자율주행 중이면 자율주행이 꺼짐) |
| 조건 | 방향키를 누름 |
| 동작 | 멈춰 있을 때 누르면 아래 표대로 움직입니다. 움직이는 중에 방향키를 누르면 먼저 멈춥니다 |
| 예외 | 장애물 정지(SAFE-02), 사람 정지(SAFE-03)는 전진에도 적용됩니다 |
| 값 | `MANUAL_FORWARD_SPEED`, `MANUAL_BACK_SPEED`, `MANUAL_TURN_SPEED` |
| 구현 | `aicar/ar.py` 수동 차량 조정 블록 |

| 키 | 동작 |
|----|------|
| `[Up]` | 전진 |
| `[Down]` | 후진, 후진 멜로디, 비상등 |
| `[Left]` / `[Right]` | 제자리 좌회전 / 우회전 |

### [초기반영] DRV-03 정지와 종료

| 항목 | 내용 |
|------|------|
| 언제 | 모든 상태 |
| 조건 | `[Space]`, `[End]`(정지) 또는 `[X]`, `[Esc]`(종료) |
| 동작 | 정지: 자율주행을 끄고 바퀴를 멈춥니다. 종료: 프로그램을 끝내고 SAFE-05로 장치를 정리합니다 |
| 예외 | 없음. 우선순위 1위입니다. 다만 지금은 바퀴만 멈추고, 울리던 경적과 서보 연속 이동은 멈추지 않습니다(SAFE-09에서 보완) |
| 값 | 없음 |
| 구현 | `aicar/ar.py` 키 입력 블록 |

### [초기반영] DRV-04 적색 신호등 정지

| 항목 | 내용 |
|------|------|
| 언제 | 순찰 (자율주행 중) |
| 조건 | 신호등 인식(`ts.py`)이 적색을 봄 |
| 동작 | 멈춥니다. 녹색을 보면 바로 출발합니다. 녹색이 없으면 적색이 마지막으로 보인 뒤 `RESTART_NUM` 프레임이 지나야 출발합니다. 적색이 계속 보이면 계속 멈춰 있습니다 |
| 예외 | 수동 주행 중에는 적용하지 않습니다 |
| 값 | `RESTART_NUM` |
| 구현 | `aicar/ar.py` 신호등 블록 (`ts.py`는 저장소에 아직 없음) |

### [미반영] DRV-05 주행 중 동물을 보면 정차

| 항목 | 내용 |
|------|------|
| 언제 | 순찰 |
| 조건 | 목표 동물이 신뢰도 `DETECT_CONF` 이상으로 보임 |
| 동작 | 바퀴를 멈추고 관찰 상태로 넘어갑니다. 관찰 지점이 아니어도 멈춥니다 |
| 예외 | 사람이 함께 보이면 SAFE-03, SAFE-06 |
| 값 | `DETECT_CONF` |
| 구현 | 없음. 지금은 주행하면서 경적만 울립니다(DET-02) |

### [미반영] DRV-06 관찰 지점 정차

| 항목 | 내용 |
|------|------|
| 언제 | 순찰 |
| 조건 | 관찰 지점 표식을 인식함 |
| 동작 | 멈추고 구역 번호를 기억한 뒤 관찰 상태로 넘어갑니다 |
| 예외 | 같은 표식은 출발 후 다시 인식해도 무시합니다 |
| 값 | `OBSERVE_SEC` |
| 구현 | 없음. 표식 종류는 11절 "결정 필요" |

## 2. 안전 (SAFE)

### [초기반영] SAFE-01 장애물 경고

| 항목 | 내용 |
|------|------|
| 언제 | 모든 상태 (`[D]`로 거리센서를 켰을 때) |
| 조건 | 전방 거리 < `HORN_DISTANCE` |
| 동작 | 화면에 정지 표시, 브레이크 램프를 켜고, 자율주행이나 전진 중이면 경적을 울립니다 |
| 예외 | 없음 |
| 값 | `HORN_DISTANCE` |
| 구현 | `aicar/ar.py` 거리센서 블록 |

### [초기반영] SAFE-02 장애물 정지

| 항목 | 내용 |
|------|------|
| 언제 | 자율주행 또는 수동 전진 중, `[D]`로 거리센서를 켰을 때 |
| 조건 | 전방 거리 < `STOP_DISTANCE` |
| 동작 | 경적을 끄고 바퀴를 멈춥니다. 자율주행이면 장애물이 없어지고 `RESTART_NUM` 프레임 뒤 다시 출발합니다. 수동 전진이면 멈춘 채로 있고 `[Up]`을 다시 눌러야 합니다 |
| 예외 | 거리센서가 꺼져 있으면 동작하지 않습니다(SAFE-10에서 보완). 우선순위 2위입니다 |
| 값 | `STOP_DISTANCE`, `RESTART_NUM` |
| 구현 | `aicar/ar.py` 거리센서 블록. 코드에는 비상등을 켜는 줄이 있지만 같은 프레임의 깜빡이 블록이 바로 꺼서 실제로는 깜빡이지 않습니다(원본 그대로). 같은 프레임에 동물이 보이면 DET-02가 경적을 다시 켭니다(10절) |

### [후기반영] SAFE-03 사람이 보이면 정지, 동물 경적 금지

| 항목 | 내용 |
|------|------|
| 언제 | 자율주행 또는 수동 전진 중, YOLO 탐지가 켜져 있을 때 |
| 조건 | 사람 탐지가 `DETECT_HOLD_SEC` 안에 있었음 |
| 동작 | 바퀴를 멈추고 화면에 `PERSON STOP`을 띄웁니다. 동물이 함께 보여도 동물 경적(DET-02)을 새로 켜지 않습니다 |
| 예외 | 장애물 경고 경적(SAFE-01)과 `[H]` 경적(LAMP-03)은 막지 않습니다. 사람이 나타나기 전에 켜진 동물 경적은 남은 프레임만큼 더 울립니다 |
| 값 | `DETECT_CONF`, `DETECT_HOLD_SEC` |
| 구현 | `aicar/ar.py` 탐지 블록, 모터 정지 블록 |

### [후기반영] SAFE-04 전원 전압 경고

| 항목 | 내용 |
|------|------|
| 언제 | 시작할 때, 주행 중 |
| 조건 | Raspberry Pi 전압 부족 또는 속도 제한 상태가 바뀜 |
| 동작 | 터미널에 경고와 해결 방법(서보 외부 전원 등)을 출력합니다. 같은 상태는 반복 출력하지 않습니다 |
| 예외 | 서보 전원선이 빠진 것은 알 수 없습니다 |
| 값 | 없음 |
| 구현 | `aicar/script/power_check.py`, `aicar/ar.py`, `aicar/gi.py` |

### [후기반영] SAFE-05 종료할 때 장치 정리

| 항목 | 내용 |
|------|------|
| 언제 | 정상 종료, 메인 루프(`main`) 실행 중 오류, `Ctrl+C` |
| 조건 | 프로그램이 끝남. 메인 루프 전 초기화(모델, 신호등 설정 파일 읽기)에서 난 오류는 정리를 거치지 않습니다 |
| 동작 | 모터 정지, 전조등 끄기, 서보 해제, GPIO 초기화, 카메라 반납 순서로 정리합니다. 한 단계가 실패해도 나머지는 계속합니다. 오류면 요약을 먼저 보여 줍니다 |
| 예외 | 없음 |
| 값 | 없음 |
| 구현 | `aicar/ar.py` `cleanup`, `reportError` |

### [미반영] SAFE-06 사람이 보이면 자극 끄기, 서보 정지

| 항목 | 내용 |
|------|------|
| 언제 | 모든 상태 |
| 조건 | 사람 탐지가 `DETECT_HOLD_SEC` 안에 있었음 (신뢰도 `PERSON_CONF` 이상) |
| 동작 | SAFE-03에 더해 기피 자극(스피커, LED, 동물 경적)을 즉시 끄고, 남은 경적 프레임도 지웁니다. 서보는 그 자리에서 멈추고, 기록을 남깁니다(LOG-01). 정차 중에도 적용합니다 |
| 예외 | 장애물 경고 경적(SAFE-01)은 사람에게 알리는 안전 신호라 허용합니다. 사람은 동물보다 낮은 신뢰도에서도 사람으로 봅니다 (놓치는 쪽이 더 위험하므로) |
| 사람 없음 판단 | 시간이 지났다는 것만으로 "사람 없음"이 되지 않습니다. `DETECT_STALE_SEC` 안의 최신 탐지 결과에 사람이 없어야 "사람 없음"입니다. 최신 결과가 없으면 SAFE-08 |
| 값 | `PERSON_CONF`, `DETECT_HOLD_SEC` |
| 구현 | 없음 |

### [미반영] SAFE-07 장애물 정지 때 자극 끄기

| 항목 | 내용 |
|------|------|
| 언제 | 관찰, 조준, 자극, 재관찰 (정차 중이라도 거리를 계속 잼) |
| 조건 | 전방 거리 < `STOP_DISTANCE` |
| 동작 | 진행 중인 자극을 끄고 관찰 불가로 기록한 뒤 복귀합니다 |
| 예외 | 없음. SAFE-02는 주행 중에만 걸리므로 정차 상태는 이 규칙이 맡습니다 |
| 값 | `STOP_DISTANCE` |
| 구현 | 없음 |

### [미반영] SAFE-08 탐지가 멈추면 자극 금지

| 항목 | 내용 |
|------|------|
| 언제 | 관찰, 조준, 자극, 재관찰 |
| 조건 | 탐지 스레드 오류(`detector.error`) 또는 마지막 탐지 결과가 `DETECT_STALE_SEC`보다 오래됨 |
| 동작 | 사람이 있는지 알 수 없으므로 자극을 끄고 관찰 불가로 기록한 뒤 복귀합니다 |
| 예외 | 없음 |
| 값 | `DETECT_STALE_SEC` (`DETECT_HOLD_SEC` 이하여야 사람 표시가 꺼지기 전에 이 규칙이 먼저 걸림) |
| 구현 | 없음. 지금은 화면에 `YOLO ERROR`만 띄우고, 사람 정지(SAFE-03)도 1초 뒤 풀린 채 계속 달립니다(DET-01) |

### [미반영] SAFE-10 거리센서 기본으로 켜기

| 항목 | 내용 |

| 언제 | 프로그램 시작 |
| 조건 | 거리센서가 연결되어 있음 |
| 동작 | `[D]`를 누르지 않아도 거리센서를 켠 상태로 시작합니다. `[D]`로 끄면 화면에 꺼짐을 계속 표시합니다 |

## 4. 서보 (AIM)

서보 1(`P17`)은 위아래, 서보 2(`P27`)는 좌우입니다. 두 서보 모두 0~180°, 중앙은 90°입니다.

### [후기반영] AIM-01 서보 수동 조작

| 항목 | 내용 |
|------|------|
| 언제 | 모든 상태 (`gi.py`, `ar.py`) |
| 조건 | 서보 키를 누름 |
| 동작 | 아래 표대로 움직입니다. 각도는 0~180°에서 자릅니다. 멈춘 뒤 `SERVO_HOLD_SEC`가 지나면 신호를 끊어 떨림을 막습니다 |
| 예외 | 서보를 못 열면 그 서보만 빼고 실행합니다 |
| 값 | `SERVO_STEP`, `SERVO_SWEEP_STEP`, `SERVO_HOLD_SEC`, `SERVO_LEFT`, `SERVO_CENTER` |
| 구현 | `aicar/ar.py`, `aicar/gi.py` 서보모터 조작 블록 |

| 서보 1 (위아래) | 서보 2 (좌우) | 동작 |
|:---:|:---:|------|
| `1` / `2` | `q` / `w` | 한쪽으로 계속 / 반대쪽으로 계속 |
| `3` / `4` | `e` / `r` | `SERVO_STEP`도씩 / 반대쪽으로 `SERVO_STEP`도씩 |
| `5` | `t` | 정지 |
| `0` | `0` | 둘 다 정지 |

- 서보 2 키는 소문자만 됩니다. 대문자는 OpenCV에서 방향키와 같은 값이라(`Q`=왼쪽, `R`=전진, `T`=후진, `W`=End) 차가 움직입니다. CapsLock을 끄고 씁니다.
- 키 이름(왼쪽, 오른쪽)은 서보 2 기준입니다. 서보 1을 위아래로 달면 실제 방향을 확인해 키 설명을 고칩니다(11절).
- 순찰 중에도 서보가 움직입니다. 카메라가 서보 위에 있으면 조향이 틀어지므로 AIM-07에서 보완합니다.

### [미반영] AIM-02 동물 쪽으로 서보 돌리기

| 항목 | 내용 |
|------|------|
| 언제 | 조준, 자극 |
| 조건 | DET-05로 고른 대상 박스가 있음, 사람 없음 |
| 동작 | 박스 중심의 화면 중심 오차를 각도로 바꿔 서보 2(좌우), 서보 1(위아래)을 돌립니다. 계산은 아래 "각도 계산" |
| 예외 | 오차가 `AIM_DEADBAND_PX` 안이면 움직이지 않습니다 (떨림 방지) |
| 값 | `CAM_HFOV_DEG`, `CAM_VFOV_DEG`, `AIM_DEADBAND_PX`, `AIM_MAX_STEP_DEG`, `AIM_INTERVAL_SEC`, `SERVO_LEFT`, `SERVO_UP` |
| 구현 | 없음 |

각도 계산 (박스 좌표는 카메라 640×480 기준):

```
오차_x = (박스 중심 x - 320) / 320        # -1(왼쪽 끝) ~ +1(오른쪽 끝)
오차_y = (박스 중심 y - 240) / 240        # -1(위 끝) ~ +1(아래 끝)

좌우 오차각 = -오차_x × CAM_HFOV_DEG / 2 × SERVO_LEFT    # 화면 왼쪽에 있으면 왼쪽으로
위아래 오차각 = -오차_y × CAM_VFOV_DEG / 2 × SERVO_UP    # 화면 위에 있으면 위로
```

순서대로 계산합니다.

1. 목표 각도를 구합니다.
   - 카메라가 서보 위에 있으면: 목표 = 지금 각도 + 오차각. 돌릴수록 대상이 화면 가운데로 옵니다.
   - 카메라가 고정이고 스피커, LED만 서보 위에 있으면: 목표 = `SERVO_CENTER` + 오차각. 화면 위치가 곧 방향입니다.
2. 목표를 서보 범위(AIM-03 포함)로 자릅니다.
3. 지금 각도에서 목표까지의 차이를 ±`AIM_MAX_STEP_DEG`로 잘라 그만큼만 움직입니다. 오차각이 아니라 이동량을 자릅니다. 오차각을 먼저 자르면 고정 카메라에서 목표가 80~100°에 갇힙니다.

## 10. 현재 코드와 다른 점

`[미반영]` 규칙을 구현할 때 함께 고칠 곳입니다.

| 규칙 | 지금 코드 (`aicar/ar.py`) | 규칙대로 하면 |
|------|---------------------------|---------------|
| DRV-05 | 주행하면서 동물이 보이면 경적만 울림 (DET-02) | 정차 후 관찰 |
| DET-03 | 한 번 보이면 바로 경적 | `CONFIRM_SEC` 동안 계속 보여야 확정 |
| SAFE-06 | 사람 신뢰도도 `DETECT_CONF`(0.25) 하나. 사람이 나타나도 이미 켜진 동물 경적이 남은 프레임만큼 울림. 1초 지나면 새 결과 없이도 "사람 없음" | 사람은 `PERSON_CONF`로 따로, 남은 경적 지우기, 최신 결과로만 "사람 없음" |
| SAFE-02 | 정지 거리 110mm | 초기 목표 200mm ([parameters.md](parameters.md)) |
| SAFE-02 | 장애물 정지로 경적을 끈 같은 프레임에 동물이 보이면 DET-02가 경적을 다시 켬 | 장애물 정지가 동물 대응보다 먼저 (우선순위 2위) |
| SAFE-07, SAFE-10 | 거리센서가 꺼진 채 시작, 정차 중에는 거리를 보지 않음 | 기본으로 켜고 정차 중에도 감시 |
| SAFE-08 | 탐지 오류 뒤에도 계속 달림 | 자극 금지, 관찰 불가 기록 |
| SAFE-09 | `[Space]`가 바퀴만 멈춤 | 경적, 서보 연속 이동도 멈춤 |
| AIM-02~07 | 서보는 키보드로만 움직이고, 순찰 중에도 움직임 | 동물 쪽 자동 조준, 주행 전 중앙 정렬, 순찰 중 서보 키는 정차 |
